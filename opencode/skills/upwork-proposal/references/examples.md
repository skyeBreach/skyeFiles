## Example 1: n8n + Google Sheets + AI + PDF

**Job:**
```
We are seeking a skilled freelancer to automate a process using N8N that involves
integrating Google Sheets, running a prompt using ChatGPT or DeepSeek, and sending
a formatted PDF via email twice a week.
```

**Winning Proposal:**
```
Hey there 👋

I can set up exactly what you need — a clean n8n workflow that pulls from
Google Sheets, runs prompts through ChatGPT/DeepSeek, generates a PDF, and
emails it twice a week.

Here's my approach:
- Connect Sheets with time-based triggers (twice weekly)
- Process data through ChatGPT/DeepSeek API with your prompt template
- Format and convert to PDF (via Google Docs or external API)
- Auto-send via Gmail on schedule
- Add error handling and logging for monitoring

I recently built a similar automated reporting system that's been running
reliably for 6 months. Happy to share details.

Available to start Monday — first working version by Thursday.

When would you like to kick off?
```

**Word count:** ~115 words

## Example 6: Complex Project with Methodology (Trust Signal)

**Job:**
```
Looking for a developer to build a production-ready automation system for our
e-commerce business. Must be reliable, well-documented, and maintainable.
Previous freelancer delivered code that broke after a week. Need someone
professional who can deliver quality work.
```

**Winning Proposal (with methodology):**
```
Hey there 👋

I understand the frustration with unreliable code. I can build a solid,
maintainable automation system for your e-commerce business.

Here's my approach:
- Document requirements first (you approve before coding starts)
- Write tests that define expected behavior
- Implement against specs and tests
- Deliver working code + specs + tests + documentation in the repo

What you'll get:
- Production-ready automation with error handling
- Test suite that verifies everything works
- Documentation explaining how it works and why
- Code you can actually maintain and extend

I follow spec-driven development — you won't get "it works on my machine."
You'll get verified, documented code.

Built similar systems handling 200+ transactions daily. Happy to share details.

When would you like to discuss requirements?
```

**Word count:** ~130 words

**Why this works:** Client explicitly mentioned reliability concerns and bad past experience. Methodology directly addresses their pain.

---

## When to Add Methodology

| Client Signal | Add Methodology? |
|---------------|------------------|
| "reliable", "production-ready" | Yes |
| "maintainable", "documented" | Yes |
| "previous freelancer failed" | Yes |
| Budget $500+ | Yes |
| Long-term/ongoing project | Yes |
| Simple one-off task | No |
| "fast and cheap" | No |
| Quick fix under $100 | No |
