# Upwork Proposal Structure

The 7-part formula that gets 24%+ response rates (industry average: 8-15%).

---

## The Framework

Clients spend only **10-15 seconds** scanning proposals initially. Structure for skimmability.

### Part 1: Hook (25 words max)

**Purpose:** Stop the scroll. Show you read their post.

**Formula:** `[Greeting] + [Their specific problem/need]`

**Examples:**
```
Hey there 👋 I can help you automate that Google Sheets → AI → PDF workflow.
```
```
Hi Sarah — saw you need Shopify order automation with n8n. That's exactly what I build.
```
```
Hey! Your email categorization project sounds perfect — I recently built something similar.
```

**DON'T:**
- "Dear Hiring Manager" (instant delete)
- "I hope this finds you well" (AI red flag)
- "I am writing to express my interest" (robotic)

---

### Part 2: Relevance (50-75 words)

**Purpose:** Prove you've done this before with results.

**Formula:** `[X similar projects] + [Quantified result]`

**Examples:**
```
I've built 15+ n8n automations for e-commerce clients, including order processing, inventory sync, and customer notifications. My last Shopify automation reduced manual work by 12 hours/week for the client.
```
```
Over the past year, I've processed and categorized 50,000+ emails using AI pipelines. One system I built achieved 94% accuracy in auto-sorting customer inquiries.
```

**Key:** Use numbers. "15+ projects", "12 hours/week saved", "94% accuracy"

---

### Part 3: Solution (50-75 words)

**Purpose:** Show them HOW you'll solve their problem.

**Format:** Bullet points for skimmability.

**Example:**
```
Here's my approach:
- Connect Google Sheets with scheduled triggers
- Process data through ChatGPT/DeepSeek API
- Format output and generate PDF
- Auto-send via Gmail on your schedule

I'll also add error handling and logging so you can monitor the workflow.
```

**Key:** Be specific to THEIR project, not generic capabilities.

---

### Part 4: Proof (30-50 words)

**Purpose:** Concrete evidence, not claims.

**Formula:** `[Past project name/type] + [Specific metric]`

**Examples:**
```
I recently built a similar workflow for a finance client — automated weekly reports from Sheets to PDF emails, running reliably for 6 months now.
```
```
My WhatsApp + n8n customer support system handles 200+ messages daily with 95% auto-resolution rate.
```

---

### Part 5: Timeline (15-25 words)

**Purpose:** Show you take deadlines seriously.

**Formula:** `[Specific date] or [Specific duration]`

**Examples:**
```
I can have the first working version ready by Friday. Full delivery within 5 days.
```
```
Available to start Monday. Estimated completion: December 15th.
```

**DON'T:** "ASAP", "as soon as possible", "quickly"

---

### Part 6: Investment (10-15 words)

**Purpose:** Clear pricing removes friction.

**Examples:**
```
Fixed rate: $XXX for the complete workflow.
```
```
Happy to discuss pricing based on scope — my typical rate for this type of project is $XX-$XX/hour.
```

**Note:** Only include if you're confident. Can skip for complex projects where scope needs discussion.

---

### Part 7: CTA (15-20 words)

**Purpose:** One clear next step. Create urgency without being pushy.

**Examples:**
```
When would you like to kick off? I'm available to discuss tomorrow.
```
```
Want me to share my screen and walk you through how I'd build this?
```
```
If this sounds like a fit, invite me and share your workflow export — I'll start with a quick diagnosis.
```

**DON'T:** "Please let me know if you have any questions" (passive)

---

## Complete Example

**Job:** Automate Google Sheets → ChatGPT → PDF → Email (twice weekly)

```
Hey there 👋

I can set up exactly what you need — a clean n8n workflow that pulls from Google Sheets, runs prompts through ChatGPT, generates a PDF, and emails it twice a week.

Here's my approach:
- Connect Sheets with time-based triggers
- Process data through ChatGPT API with your prompt template
- Format and convert to PDF (via Google Docs or external API)
- Auto-send via Gmail on schedule

I recently built a similar automated reporting system for a finance client — it's been running reliably for 6 months. Happy to share details.

Available to start Monday. First working version by Thursday.

When would you like to kick off?
```

**Word count:** ~120 words (well under 250)

---

## Length Guidelines

| Proposal Length | Effectiveness |
|-----------------|---------------|
| Under 100 words | Too brief, may seem low-effort |
| **150-250 words** | **Optimal** |
| 250-400 words | Acceptable if project is complex |
| 400+ words | Too long, gets skimmed |

Rule: **If you can say it in fewer words, do it.**
